# 10. ATS Scoring Engine

Don't let Gemini randomly decide the entire score.

Build a basic deterministic scoring engine.

For example:

```text
Keyword Match       25%
Technical Skills    25%
Experience          20%
Projects            15%
Education           10%
Structure            5%
```

Then:

```text
ATS Score =
keyword_score * 0.25
+ skill_score * 0.25
+ experience_score * 0.20
+ project_score * 0.15
+ education_score * 0.10
+ structure_score * 0.05
```

This is much more defensible technically.

Gemini provides **semantic interpretation**, while Python handles deterministic calculations.

That's a strong architectural decision to explain to the judges.
